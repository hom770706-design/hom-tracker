# 台指期常見策略整理（技術面 + 籌碼面）

彙整自公開網路資料，供本專案策略開發參考。分「技術面」「籌碼面」與「兩者搭配」三部分，
最後對照本框架目前的實作狀態。

> ⚠️ 提醒：任何策略在真實下單前，都應以模擬盤充分驗證，並嚴設停損。
> 單一指標容易被騙、籌碼面會落後、回測績效不代表未來。

## 一、技術面策略

### 順勢 / 趨勢型（趨勢盤好用）
| 策略 | 邏輯 | 常用指標 |
|------|------|----------|
| 均線多空 | 站上 20MA 偏多、跌破偏空；60MA 為長線保護 | MA(20/60) |
| 均線交叉 | 短均上穿長均做多、下穿做空 | 雙均線 |
| MACD 趨勢 | 柱狀體翻紅/翻綠、零軸穿越、背離 | MACD |

### 突破型（當沖最主流）
| 策略 | 邏輯 |
|------|------|
| 開盤區間突破 (ORB) | 開盤後 N 分鐘的高低點，突破就順勢進場 |
| 前高前低突破 | 突破昨日高/低，或盤中 5/30 分K 支撐壓力 |
| 布林通道開口 | 喇叭口打開＝強趨勢啟動，順勢進場 |

### 逆勢 / 均值回歸型（盤整盤好用，趨勢來會失靈）
| 策略 | 邏輯 | 指標 |
|------|------|------|
| KD 超買超賣 | 低檔黃金交叉買、高檔死亡交叉賣 | KD |
| RSI 超買超賣 | RSI <30 買、>70 賣；背離抓轉折 | RSI |
| 布林通道區間 | 碰下軌買、碰上軌賣（震盪時） | 布林 |
| 軸點反轉 (Pivot) | 用樞紐點算支撐壓力，碰到反手 | Pivot |

### 動能 / 波動型
| 策略 | 邏輯 |
|------|------|
| 動能進場 | 行情剛發動、量能爆出時卡位 |
| 委買委賣能量 | 盤中累計多空單筆數差，判斷力道 |
| ATR 波動濾網 | 波動異常大（ATR > 過去一年 90 分位）就停手空手 |

## 二、籌碼面（台指期特色）

| 指標 | 怎麼看 | 資料來源 |
|------|--------|----------|
| 三大法人未平倉 | 外資/投信/自營的多空淨額，判斷法人偏多空 | 期交所、FinMind（免費） |
| 外資期貨未平倉淨額 | 淨多單增→偏多；淨空單增→偏空；創新高/低留意反轉 | 期交所、FinMind |
| 大額交易人未平倉 | 前十大交易人多空，看大戶方向 | 期交所 |
| 選擇權 Put/Call Ratio | 未平倉 P/C 比反映情緒（落後指數約 14 天，參考用） | 期交所 |
| 選擇權最大未平倉區 | 大量 Call/Put 履約價＝潛在壓力/支撐 | 期交所 |

> 共識：籌碼面適合「定方向/情緒」，單看不能預測價格，要搭技術面與現貨量能。

## 三、技術 + 籌碼 怎麼搭（實用重點）

核心邏輯是**分工**：

> **籌碼定「方向偏好」(bias) → 技術定「進出場點位」**

範例：
- 外資期貨淨多單增加（籌碼偏多）的日子 → 當天只做多，用 ORB 突破或 KD 低檔交叉進場。
- 法人偏空的日子 → 當天只做空。
- 再加 ATR 波動濾網，亂盤就不做。

好處：同一套技術策略加上籌碼過濾，可砍掉逆風交易，通常提升穩定度、降低回檔。

> 避免未來函數：期交所籌碼是每天收盤後才公布，所以「第 D 天的 bias」必須用
> 「第 D-1 天的籌碼」計算（本框架 `foreign_oi_bias()` 已做 shift(1) 處理）。
